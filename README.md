# java-calculator-precourse

## ✨기능 목록
### 입력 문자열 출력 및 입력 기능
- [X] "덧셈할 문자열을 입력해 주세요." 문구를 출력하여 사용자에게 입력을 유도한다.
- [X] 사용자의 문자열 입력을 받을 수 있도록 입력 라인을 추가한다.

### 커스텀 구분자 추출 기능
- [X] 입력 문자열에서 `"//"`와 `"\n"` 사이의 문자를 추출하여 **커스텀 구분자**로 지정한다.
- [X] 커스텀 구분자가 존재하지 않는 경우 기본 구분자(`,`, `:`)를 사용한다.

### 구분자 기준 분리 기능
- [X] 입력 문자열을 **커스텀 구분자 또는 기본 구분자**를 기준으로 분리한다.
- [X] 분리된 각 문자열을 정수로 변환하여 계산 가능한 형태로 반환한다.

### 계산 기능
- [X] 분리된 모든 숫자를 순회하며 합계를 계산한다.
- [X] 빈 문자열 입력 시 합계는 `0`을 반환한다.
- [X] 숫자 이외의 입력이 포함된 경우 예외를 발생시킨다.

### 결과 출력 기능
- [X] `"결과 : %d"` 형식으로 계산된 결과를 출력한다.
- [X] 결과 출력 후 프로그램이 정상 종료되어야 한다.

## ⚠️ 예외 처리 조건
### 예외 발생 시 처리 방식
- 사용자가 잘못된 값을 입력한 경우  
  → `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.

### 형식 관련 예외
- [X] 커스텀 구분자 형식이 올바르지 않은 경우  
  (예: `"//;\n1;2;3"` 형태가 아닐 때, `"//;1;2;3"`, `"//;\\n1"` 포함)
- [X] 입력 문자열에 기본 구분자(`,`, `:`) 또는 커스텀 구분자가 존재하지 않아 분리할 수 없는 경우
- [X] 구분자 뒤에 값이 없는 경우 또는 연속된 구분자로 인해 빈 문자열이 발생한 경우  
  (예: `"1,2,"`, `"1::2"`)

### 값 관련 예외
- [X] 구분자 사이 값이 숫자가 아니어서 파싱할 수 없는 경우  
  (예: `"1,a,3"`)

### 실행 관련 예외
- [X] 입력이 비어 있거나(`null`, 공백 포함) 완전히 입력되지 않은 경우
